## Security patch

The OSV advisory states that pytest through `9.0.2` on UNIX used predictable `/tmp/pytest-of-{user}` handling that could allow another local user to cause a denial of service or possibly gain privileges; version `9.0.3` is the first fixed release.[1] This project now requires pytest `>=9.0.3,<10`, and the regenerated lock resolves pytest `9.1.1`.

A dependency audit of the synchronized project environment reported no known vulnerabilities after the update. The local `aeon-context-kernel` package was skipped because it is not published on PyPI.

## Verification record

The patched environment passed 122 tests, Ruff formatting and lint, strict Mypy, the local example, the observe/warn/enforce simulator demo, repository metadata/link validation, package builds, and the deterministic smoke benchmark. The S0 runtime modules, harness versions, scenarios, predicates, and decision behavior were unchanged by this patch.

The previously generated smoke, pilot, and full S0 conformance artifacts remain mechanical simulator evidence. They are not authenticated production evidence and do not establish real-model safety, utility, or long-context effectiveness.
